# The Honest Ballot

A civic design project that makes the Electoral College visible at the point of voting.

Most presidential ballots feel like a direct vote for President.  
This project argues that the ballot should more clearly show what the voter is **legally doing**: helping choose a **slate of electors** that the state will appoint.

**The Honest Ballot** is a prototype website that explores what a more truthful presidential ballot could look like.

## What this project does

This site:

- explains the basic mechanics of the Electoral College in plain language
- contrasts a standard presidential ballot with a more transparent design
- shows a prototype ballot that puts **elector selection** front and center
- introduces a small amount of voting-method language, including:
  - **Ballot style:** Pick one
  - **Counting rule:** Plurality
  - **Winner rule:** Most votes wins
  - **Winner award:** All state electors

## Why this exists

In a presidential election, voters are usually shown a ballot that looks more direct than the legal system really is.

This project is not trying to make voting harder to understand.  
It is trying to make the system **more honest to the voter**.

The core idea is simple:

> A democratic ballot should not hide the mechanism it uses.

If electors are part of the process, the ballot should say so clearly.

## Project status

This is an evolving prototype.

The current version uses **Arizona** as the example state.  
Planned future improvements may include:

- support for all 50 states plus DC
- a **Pick a State** dropdown
- optional browser-based state detection
- state-specific elector counts and winner rules
- special handling for Maine and Nebraska
- side-by-side state comparisons
- expanded educational content on Electoral College design and reform
